# Publishing and Revisions
*Applies to: Stardew Valley 1.6.15+ Last reviewed: 2026-10-02*

## Sharing Your Collection

When you create a collection, you choose how it is shared:

- **Private link.** Share with friends without making the collection public.
- **Unlisted.** The collection does not appear in search results. People can still open it from the link.
- **Listed.** A public collection, only if you want the community to be able to discover it.

## Install as New vs Replicate

These methods control how mods are installed and whether players can change installation options.

### Fresh Install (Install as New)

- Performs a clean install.
- Presents the FOMOD installer when the mod has one.
- The player chooses the installer options.

Use Install as New when you want players to customize the installation, or when a mod has important installation choices.

### Replicate

- Reproduces the exact folder structure by hash.
- Requires the Exact Only version policy.
- Use it for reorganized mod layouts.

Replicate gives players the folder structure you created. That is required if you reorganized mod files or merged assets, and it is critical for collections that use a custom folder structure. [Preparing Mods for a Collection](preparing-mods-for-a-collection.md) defines Exact Only, Prefer Exact, and Latest.

### Same Install Options

- Reuses the curator's saved installer choices.
- Skips prompts.
- Works only with curated FOMOD settings.

{% hint style="info" %}
Use Same Install Options when players should get your configuration without prompts. That keeps installations consistent.
{% endhint %}

## Private vs Public Collections

### Private collections

- Unlisted on Nexus Mods, so they do not appear in search results.
- Shareable by a private link.
- Suited to personal use, friends-only sharing, or organizing your custom mods.
- Help you preserve your additions through collection updates.
- Make it easier to reinstall your favorite mods.
- Let you keep track of what you have added.

### Public collections

- Listed on Nexus Mods.
- Discoverable in search.
- Suited to sharing with the community.
- Require you to follow [Nexus Mods Guidelines for Collections](https://help.nexusmods.com/article/115-guidelines-for-collections).

{% hint style="danger" %}
Listed or unlisted, a collection's link remains active indefinitely once published. Nexus Mods currently does not support deleting or archiving collections.
{% endhint %}
