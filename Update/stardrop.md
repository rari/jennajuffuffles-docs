# Update with Stardrop
*Applies to: Stardew Valley 1.6.15+ Last reviewed: 2026-10-02*

{% hint style="danger" %}
Update the collection, not individual mods. Collections are tested together. Updating individual mods outside a collection revision can cause unexpected behavior.
{% endhint %}

Update a collection in Stardrop with a current [release](https://github.com/Floogen/Stardrop/releases).

1. Open **Nexus Mods** > **Collections**.
2. Select the collection in the left panel.
3. In the right panel, click **Update** in the upper right.

What updating in Stardrop does:

- A newer revision is applied to the same protected profile. Stardrop does not create a second profile for the update.
- Mods you turned off stay off. Mods you added, notes, and preserved configuration stay.
- Entries the new revision drops are removed from the profile. Their files can remain on disk.
- An entry pinned to an exact file should not raise its own update prompt. Wait for the collection revision.

If a download fails part way through, the installed revision number stays on the last revision that fully landed. Finish the remaining manual downloads before you treat the update as done.

Only a collection Stardrop installed can be updated with Stardrop.
