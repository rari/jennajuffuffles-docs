# Collection / Update Issues
*Applies to: Stardew Valley 1.6.15+ Last reviewed: 2026-10-02*

{% hint style="danger" %}
Update the collection, not individual mods. The collections are tested as a set. A newer file of one mod can break the others.
{% endhint %}

An update uses a different procedure in each manager. Do not follow another manager's steps.

- [Update with Vortex](../Update/vortex.md)
- [Update with Stardrop](../Update/stardrop.md)
- [Update with Amethyst](../Update/amethyst.md)

## Mods missing after an update

### What you see

SMAPI loads fewer mods than before, or optional mods you had enabled are off.

### What to do

1. Read [Your SMAPI Log](your-smapi-log.md) and note which mods are missing.
2. Check the collection's Change Log to see if the mod was intentionally removed by the curator.
2. Use your manager's update page. In Vortex, re-enable the collection and choose recommended mods. That click is on [Update with Vortex](../Update/vortex.md), not here.
3. Check [Known Issues](known-issues.md).

## Duplicate mods

### What you see

SMAPI reports a duplicate mod, or two copies of the same mod are listed.

### What to do

Allow the manager to remove the old file when it asks. Skipping that removal can leave duplicates that will prevent mods from loading. 

## The save will not load after an update

Back up the save before you change anything else. See [Installing to an Existing Save](../Install/installing-to-an-existing-save.md) if the update added or removed a farm map, greenhouse, or expansion.
