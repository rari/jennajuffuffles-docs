# Hotkeys
*Applies to: Stardew Valley 1.6.15+ Last reviewed: 2026-10-02*

Bindings below were captured from **Generic Mod Config Menu** with **Stardew Valley VERY Expanded**, **Aesthetic Valley Fairycore**, **Aesthetic Valley Fairycore Extra Textures**, **Aesthetic Valley Witchcore**, and **Aesthetic Valley Witchcore Extra Textures** installed together. That combined setup was used to capture keys. 

Your keys may differ if you changed them in **Settings > Mod Options** (in-game) or from the title screen (gear icon, lower left). This page may also fall out of sync with the newest version of the collection slightly.

Mods are grouped by **Nexus collection**. Only mods that registered a keybind in GMCM appear here.

## Aesthetic Valley Fairycore or Witchcore (+ Extras)

| Mod | Action | Key |
| --- | --- | --- |
| Fashion Sense | Hand mirror / quick menu | `G` |
| Furniture Framework | Place furniture in a slot | `Left click` |
| Furniture Framework | Interact with slotted furniture | `Right click` |
| Generic Mod Config Menu | Open menu | `Numpad -` (`Subtract`) |
| Happy Home Designer | Give from catalogue (hold while clicking) | `LeftShift` |
| Happy Home Designer | Favorite (hold while clicking) | `LeftControl` |
| Happy Home Designer | Delete held item | `Delete` |
| Happy Home Designer | Open catalogue anywhere | `L` |
| Precise Furniture | Move | `Left` / `Right` / `Up` / `Down` |
| Precise Furniture | Speed modifier | `LeftAlt` |
| Precise Furniture | Lock furniture | `Right click` |
| Precise Furniture | Blacklist hovered piece | `Right click` |
| ReMapping Earthy ReSync | Resync Remapping tokens | `F7` |

Lock furniture and Blacklist hovered piece both use `Right click` in this profile. Check **Mod Options** for how the mod distinguishes them.

Check Keybinds in Generic Mod Config Menu (upper left) to view all custom keybinds. All keybinds listed here (and more) can be modified in Generic Mod Config Menu per mod.
