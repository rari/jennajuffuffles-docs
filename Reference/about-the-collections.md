# About the Collections
*Applies to: Stardew Valley 1.6.15+ Last reviewed: 2026-10-02*

## Stardew Valley VERY Expanded

Stardew Valley VERY Expanded (svVe) is a **curated mod collection** that extends this familiar world far beyond Pelican Town while preserving the cozy, vanilla charm of the original game.

**Download on Nexus:** [Stardew Valley VERY Expanded](https://www.nexusmods.com/games/stardewvalley/collections/tckf0m)

### Special Features

- **Major Expansions** including over 50 new NPCs:
  - Stardew Valley Expanded - The largest expansion mod
  - Ridgeside Village - An entirely new village with 45+ NPCs
  - East Scarp - Major area expansion east of Pelican Town
  - Sword & Sorcery - Fantasy expansion with custom skill trees
- **Over 90 total mods** with major expansions and quality-of-life improvements
- **Massive included farm map** perfect for co-op play
- **Focus on the game not the wiki** with World Navigator, Lookup Anything, and UI Info Suite 2
- **Quality-of-life mods** like Automate, Chests Anywhere, and NPC Map Locations

Default keys and GMCM tips: [Hotkeys](hotkeys.md#stardew-valley-very-expanded).

### Translation Collections

Language packs are available for Stardew Valley VERY Expanded. The mods in these packs are created by various translators, so please support them and their work by endorsing them on Nexus.

See the collection's About tab on Nexus for available translation collections.

## Oops! All Portraits: Nyapu

[Oops! All Portraits: Nyapu](https://www.nexusmods.com/games/stardewvalley/collections/falitk) adds Nyapu character portraits to a Stardew Valley VERY Expanded profile.

Nyapu and nyapu-style portraits are widely loved for their classic farm-sim look, and they cover a lot of characters. They are also difficult to install in Vortex. This collection adds them to Stardew Valley VERY Expanded for you.

## Aesthetic Valley Extra Textures

[Aesthetic Valley Fairycore Extra Textures](https://www.nexusmods.com/games/stardewvalley/collections/i8ulwo/) adds a curated set of fairy-themed textures. [Aesthetic Valley Witchcore Extra Textures](https://www.nexusmods.com/games/stardewvalley/collections/ufo0fl/) adds a curated set of witch-themed textures. Both pair with JennaJuffuffles collections and other compatible setups.

Install one, both together, or either one with any other collection in the pack.

These collections include the outfits, furniture, and other texture packs previously included in Fairycore and Witchcore.

- **Fashion Sense** - Hats, accessories, hairstyles, and outfits. Open it anywhere with `G`. A hand mirror is not required.
- **Alternative Textures** - Swap textures on furniture, animals, buildings, and other objects. Buy a Paint Bucket from Robin.
- **Happy Home Designer** - Place furniture from the catalog while you walk around, including Alternative Textures skins.
- **Creative Neighbors** - After you meet them, neighbors mail Alternative Textures tools.

Keys for these collections: [Hotkeys](hotkeys.md#aesthetic-valley-fairycore-or-witchcore-extras).

## Multiplayer Support

### What Works

- **Online co-op multiplayer** is supported
- All players must have matching mod setups (same collection, same versions)
- Collections are designed for co-op groups who need matching setups
- Configuration files should match across all players

### What Doesn't Work

- Mismatched mods or mod versions may cause crashes or prevent games from even connecting
- Sword & Sorcery's last dungeon does not support co-op 
- Different optional mod selections can cause problems
- Custom configurations that differ between players may cause issues
- Individual mod updates outside of collection updates can break compatibility with other mods in the collection

### Best Practices

1. All players install the same collection
2. Install all optional mods (unless combining collections or given a 'skip' that indicates otherwise)
3. Keep configurations synchronized with eachother
4. Create a plan when and if to update to the newest revision
5. Make sure all players can create a new farm solo before booting up multiplayer

## Splitscreen Support

- **Local co-op multiplayer** is technically possible but not recommended for all players.
- Large collections significantly impact performance in splitscreen
- Some mods may not have splitscreen support

For best results, test splitscreen with your specific setup before committing to a long play session.

## Mobile Support

Mobile support is not considered at this time, but a mobile alternative list could be considered in the future if there is interest.
