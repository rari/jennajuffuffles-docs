# Using a Controller
*Applies to: Stardew Valley 1.6.15+ Last reviewed: 2026-10-02*

Many mods in the collections include controller support with default button mappings. Change those buttons in each mod's **Generic Mod Config Menu (GMCM)** settings. Full keyboard and controller defaults are on [Hotkeys](hotkeys.md).

## Accessing Controller Settings

1. Launch the game.
2. From the title screen, click the **gear button** (lower left) to open GMCM.
3. Navigate to individual mod settings to customize controller buttons.

## Default Controller Mappings

### Convenient Inventory

- **Quickstack:** Left Stick
- **Favorite item:** Left Shoulder

### Other Mods

Controller support varies by mod. Check each mod's GMCM settings for available controller options.

## Customizing Controller Buttons

1. From the title screen, click the **gear button** to open GMCM.
2. Select the mod you want to customize.
3. Look for controller and keybind settings.
4. Assign your preferred buttons.
5. Settings save automatically.

## Troubleshooting

### Controller not working

- **Controller connection timing:** There is a known issue where starting with a controller connected can make input control both the game and the SMAPI console. This can cause accidental console closure and crash the session. See [Known Issues](../Troubleshooting/known-issues.md#controller-input-captured-by-smapi-console-on-start-up).
- Check that controller support is enabled in the mod's GMCM settings.
- Some mods may require enabling controller support in their configuration.

### Buttons not responding

- Verify the controller is recognized by Windows or your system.
- Check mod-specific controller settings in GMCM.
- Try resetting to default and reassigning buttons.
